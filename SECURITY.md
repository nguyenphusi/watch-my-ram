# Security policy

watch-my-ram runs read-only commands on your Mac (see [Is it safe?](README.md#is-it-safe)). If you find a way it could leak data, run something it shouldn't, or break that read-only promise, please report it privately.

## Report a vulnerability

Use GitHub's private reporting: [Report a vulnerability](https://github.com/nguyenphusi/watch-my-ram/security/advisories/new). Please don't open a public issue for security problems.

Include what you found, how to reproduce it, and the watch-my-ram and Claude Code versions. You should get a reply within a week.

## Supported versions

Only the latest release gets security fixes.
